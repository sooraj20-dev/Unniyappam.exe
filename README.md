A stylized, interactive, and hilarious **3D Kerala Cooking Game & Meme Experience** built with **React Three Fiber (Three.js)** and **TypeScript**. 

Craft traditional golden-crisp Kerala **Unniyappams** in a warm miniature kitchen diorama, follow Ammachi's hilarious cooking advice, and undergo a serious culinary audit before unlocking the legendary Malayali prank!

---

## 🌟 Features

### 🌴 1. Authentic Kerala Miniature Kitchen Diorama
* **Interactive 3D Props**: Low-poly cast-iron *appachatti* (with 15 distinct cavities), a realistic tabletop gas stove with burner grates, LPG cylinder with flexible hose, brass mixing bowl, wooden spoon, oil bottle, and fresh banana leaf plate.
* **Procedural PBR Textures**: Banana peel textures, dark jaggery syrup, brushed stainless steel, and cast-iron pan seasoning.
* **Dynamic Visual Effects**: Rising steam, heat waves, and overheat black smoke if the flame is turned too high!

---

### 👵 2. Ammachi's Live Commentary (`അമ്മായിയുടെ കമന്ററി`)
* An interactive, floating cartoon speech bubble featuring **Ammachi (👵)** who reacts dynamically to every player action with pure Malayali humor:

  * *Stirring Batter*: *"ഇളക്ക് മോനേ ഇളക്ക്... കൈ കുഴഞ്ഞാൽ അടുത്ത ആൾക്ക് കൊടുക്ക്! കട്ട പാടില്ല! 💪🥣"*
  * *High Flame Alert*: *"⚠️ അയ്യോ തീ കൂട്ടി കരിക്കല്ലേ! അടുക്കള മൊത്തം പുകയായി! വേഗം Medium-ലേക്ക് ആക്ക്! 🔥"*
  * *Cavity Counting 1–15*: Real-time witty commentary as you tap each cavity (*"കുഴി 6: നിങ്ങൾക്ക് വേറെ പണിയൊന്നുമില്ലേ?! 😂"*).
  * *Tap the avatar anytime to hear randomized Kerala kitchen comedy!*

### 🍳 3. The Complete 9-Stage Culinary Flow
1. **🍌 ചേരുവകൾ ചേർക്കുക (Add Ingredients)**: Drag Palayamkodan bananas, dark jaggery syrup, cardamom powder, and rice flour into the mixing bowl.
2. **🥣 മാവ് കുഴക്കുക (Mix Batter)**: Swirl the wooden spoon in circles until the batter reaches silky-smooth perfection.
3. **🔥 ചട്ടി ചൂടാക്കുക (Heat Pan)**: Turn the tabletop stove knob to the sweet spot (Medium Flame).
4. **🥥 വെളിച്ചെണ്ണ ഒഴിക്കുക (Pour Coconut Oil)**: Pour pure coconut oil into all 15 cavities of the appachatti.
5. **🫓 മാവൊഴിക്കുക (Pour Batter)**: Ladle the sweet spiced batter into each sizzling cavity.
6. **✨ മൊരിഞ്ഞു വരട്ടെ (Sizzle & Cook)**: Listen to realistic sizzling and watch the golden crust form.
7. **🔄 മറിച്ചിടുക (Flip Appams)**: Flip all 15 unniyappams 180° with a skewer to toast the back side.
8. **🍃 വാഴയിലയിൽ വിളമ്പുക (Serve on Banana Leaf)**: Plate all 15 piping hot unniyappams.
9. **🔍 കുഴി എണ്ണൽ ഓഡിറ്റ് (Count the Kuzhi)**: The mandatory "culinary audit" where you tap and count all 15 cavities before eating.

### 🔊 6. Procedural Web Audio Engine
* No bulky external audio files — all sounds are generated in real-time using the **Web Audio API**:
  * Realistic liquid stream pouring for oil & batter
  * Squelchy batter stirring resonance
  * Crackling oil sizzling with randomized pops
  * Ascending harmonic musical scale for cavity counting (15 musical tones)
  * Comedic cartoon boings, buzzers, victory fanfare, and ambient background melodies
* **Mobile Haptic Feedback**: Integrated `navigator.vibrate` triggers on taps and button clicks.

---

### 📱 7. Mobile-First & Responsive Experience
* **Full Viewport Support (`100dvh`)**: Optimized for mobile devices with safe-area insets (`env(safe-area-inset-top)` & `env(safe-area-inset-bottom)`).
* **Touch-Friendly Controls**: Generous touch targets (min 44px) placed in the thumb zone.
* **Collapsible Camera Angles**: Quick floating menu to switch between:
  * 📐 **ഐസോമെട്രിക് (Isometric)**
  * 🔍 **ക്ലോസ് അപ്പ് (Close-Up)**
  * ⬇️ **ടോപ്പ് വ്യൂ (Top-Down)**
  * 🔄 **സൈഡ് വ്യൂ (Side Angle)**
* **Orientation Support**: Fluid layouts for portrait and landscape modes.

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (version 18+ recommended)
* `npm` or `yarn` or `pnpm`

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/your-username/unniyappam-3d.git

# 2. Navigate to project directory
cd unniyappam-3d

# 3. Install dependencies
npm install
```

### Running Locally
```bash
# Start Vite development server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production
```bash
# Type check and build optimized bundle
npm run build

# Preview production build locally
npm run preview
```

## ☁️ Deployment (Vercel)

The repository includes a ready-to-use [`vercel.json`](./vercel.json) file with pre-configured SPA routing, security headers, and asset caching.

### Option 1: Vercel Dashboard (Recommended)
1. Push your code to GitHub / GitLab / Bitbucket.
2. Import the project into the [Vercel Dashboard](https://vercel.com/new).
3. Vercel will automatically detect Vite and run `npm run build`.

### Option 2: Vercel CLI
```bash
# Deploy to preview
npx vercel

# Deploy to production
npx vercel --prod
```
